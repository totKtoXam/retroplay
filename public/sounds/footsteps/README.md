# Шаги

Записи с [Freesound](https://freesound.org), все под лицензией [CC0](https://creativecommons.org/publicdomain/zero/1.0/): указывать авторов не обязательно, список — чтобы найти исходники.

В каждом файле одиночные шаги подряд, разделённые тишиной 0,25 с. Игра делит файл по тишине (`splitSteps` в `lib/footsteps.ts`), поэтому при замене файла держите паузы между шагами не короче 0,12 с. Формат — MP3, моно, 44,1 кГц, 96 кбит/с. Шаги вырезаны из HQ-превью Freesound и выровнены по пиковой громкости огибающей.
