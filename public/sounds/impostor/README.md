# Звуки режима «Предатель»

Записи с [Freesound](https://freesound.org), все под лицензией [CC0](https://creativecommons.org/publicdomain/zero/1.0/): указывать авторов не обязательно, список — чтобы найти исходники. Играет их `components/impostor-sounds.ts`, когда — решает `lib/impostor-sound-events.ts`.

Из HQ-превью Freesound убрана тишина в начале, длина ограничена, конец плавно затухает, громкость выровнена по пику. Формат — MP3, моно, 44,1 кГц, 128 кбит/с.
