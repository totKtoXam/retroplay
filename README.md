# Jinaly · Retro 3D

Совместные ретроспективы в браузере: игровой мир от третьего лица и обычная доска работают с одним состоянием комнаты. React, TypeScript, Three.js, Vinext, Cloudflare D1.

## Запуск

Нужны Node.js 22.13+ и npm. В PowerShell используйте `npm.cmd`.

```sh
npm ci
npm run db:local
npm run dev -- --host 0.0.0.0
```

Откройте http://localhost:3000. Создайте комнату, введите имя и передайте ссылку участникам. Для подключения с другого компьютера нужен доступный ему адрес сервера: `localhost` обозначает компьютер самого участника. Веб-публикация Sites по умолчанию доступна только владельцу; для команды необходимо отдельно настроить аудиторию сайта.

Комнаты и карточки сохраняются в D1. Локальная база находится в `.wrangler` и не попадает в Git или веб-публикацию. Локальное и опубликованное приложения имеют разные базы. Не удаляйте `.wrangler`, если нужны локальные комнаты.

## Управление

| Действие                    | Ввод                                                          |
| --------------------------- | ------------------------------------------------------------- |
| Начать / продолжить игру    | Клик по миру или «Играть»                                     |
| Камера                      | Движение мыши без удержания кнопок                            |
| Курсор для меню             | Esc                                                           |
| Движение                    | WASD                                                          |
| Прыжок                      | Пробел                                                        |
| Сесть / встать              | C                                                             |
| Лечь                        | Двойное C                                                     |
| Присесть / медленный шаг    | Удерживать Ctrl / Shift                                       |
| Первое / третье лицо        | V или кнопки FPP / TPP                                        |
| Прицеливание / перезарядка  | Удерживать ПКМ / R                                            |
| Планшет / стикер            | Колесо выбирает good / bad / stop / start, E открывает стикер |
| Вернуть камеру за персонажа | F                                                             |
| Приближение / отдаление     | Alt + колесо, кнопки камеры                                   |
| Быстрые предметы            | 1–4: краскомёт, конфетти, планшет, гранаты                    |
| Снаряжение                  | Q / I; клик подтверждает выбор, Esc отменяет                  |
| Краска / конфетти           | 1 / 2, затем ЛКМ                                              |
| Участники, задержка, FPS    | Удерживать Tab или кнопка участников                          |

Переключение V сохраняет направление прицеливания; первое лицо показывает руки с оружием, третье лицо защищено от столкновений камеры со стенами. Выбор обзора сохраняется на устройстве. ПКМ приближает прицел, R перезаряжает: краска — 24 заряда, конфетти — 6, запас бесконечный. Смена инструмента отменяет незавершённую перезарядку. Анимации приседания, прицеливания и перезарядки передаются другим участникам.

Первый клик активирует обзор и не стреляет. При разрешённом Pointer Lock курсор захватывается и камера вращается неограниченно. При запрете захвата во встроенном браузере обзор работает внутри окна; у его краёв продолжается горизонтальный поворот. Esc возвращает курсор. Панели приостанавливают игровой ввод. Персонаж плавно следует за направлением камеры; A/D — движение боком, S — назад. Чувствительность и инверсия камеры настраиваются локально.

Для Ctrl+W и других сочетаний, зарезервированных браузером, включите полный экран кнопкой в шапке. При поддержке браузером запрашивается Keyboard Lock. Встроенное окно может не поддерживать системный захват; разрешения браузера приложение не обходит.

Время суток и сезон меняет ведущий кнопкой над миром. Оформление и интерьер находятся в настройках мира. Настройки встречи в шапке содержат приватность и анонимность; название редактируется нажатием на него. Блок FPS и пинга открывает локальные настройки графики и лимит 20 / 30 / 60 FPS. Есть темы Наурыза, Дня единства, Дня Республики, Дня независимости, Нового года и горного лагеря. Краска постепенно исчезает; игровые эффекты не меняют карточки.

## Оформление, инструменты и музыка

Два визуальных стиля: Tactical — контрастное окружение с каменными и металлическими павильонами, корпусами кампуса, цветными порталами, дальними горами и отражениями неба; Аниме — контурные персонажи, парящие острова и лепестки. Авторская модель AERO имеет отдельные поверхности лица, одежды, перчаток и обуви; её суставы сохраняют общие анимации движения. Tactical использует собственные модели и материалы с ориентиром на читаемость тактических шутеров. Графика работает на Three.js / WebGL. Экономичный режим использует статические тени, высокий — динамические мягкие тени и деликатный bloom. Время суток, сезоны и интерьер работают в обоих стилях.

В 3D доступны четыре быстрых слота. Вращение или нажатие колеса открывает круг вариантов текущего предмета. Колесо и стрелки меняют подсветку, клик / Enter подтверждают выбор, Esc отменяет. Q открывает снаряжение. Планшет хранит выбранный раздел; E открывает цветной стикер с одним текстовым полем. Сохранение — галочка или Ctrl+Enter. Инструменты рисования доступны в обычной доске.

Краскомёт имеет восемь цветов. Конфетти: классика, звёзды, снежки, сердца, цифры, лепестки, кометы и шаңырақ. Гранаты: пиньята, взрыв красок, снежный шар, валентинка, пиксельная и метеор. Бросок ЛКМ, задержка взрыва 1,1 секунды, радиус 4 м. Урон: краска 20 HP, конфетти 5 HP, гранаты 45 HP; самоповреждения нет. HP рассчитывается сервером. Возрождение по умолчанию через 5 секунд, ведущий задаёт 1–30 секунд в настройках мира. Старые пакеты позиции после возрождения игнорируются.

Анонимные участники носят бумажные пакеты со смайликом; сервер не передаёт их имена. Приватный стикер виден другим участникам как цветная карточка с каракулями. Текст и остальные приватные поля удаляются из ответа сервера; автор видит и раскрывает свою запись.

Jinaly Radio запускается по нажатию Play: четыре оригинальные синтезированные аранжировки, выбор трека, пауза и громкость. Музыку слышит только текущий пользователь; автоматического запуска нет. Аудиофайлы не загружаются: музыка создаётся Web Audio API на устройстве. Звуки событий включаются отдельно.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
# При работающем localhost:3000:
npm run test:integration
npm run build
```

`lint` проверяет код приложения, API и тесты. Неиспользуемые компоненты исходного shadcn-каталога `components/ui` не входят в этот lint scope; весь TypeScript входит в typecheck.

Модель проверяется на права ведущего, приватность, анонимность, голосование, архив и импорт. HTTP-проверка создаёт отдельные тестовые сессии и комнаты, проверяет конкурентные записи, лимит голосов, историю, отмену, изоляцию комнат и передачу краски; отдельная проверка проверяет HP, задержку гранат, дедупликацию урона, возрождение, старые пакеты позиции и анонимность. Затем тестовые комнаты архивируются.

## Архитектура и ограничения

- Сервер выдаёт HttpOnly cookie; публичный ID участника — SHA-256 от сессионного секрета, а не сам секрет.
- Содержимое чужих приватных карточек и чужие активные голоса исключаются из ответа сервера. Проверка прав выполняется в API.
- Изменения комнат проходят через контроль версии и атомарный пакет D1; история хранит последние 40 операций.
- Присутствие и игровые события синхронизируются периодическим HTTP-опросом примерно раз в секунду с интерполяцией аватаров. Это ещё не транспорт для динамичного соревновательного шутера.
- Геометрия объединяется по материалам, конфетти используют instancing, 3D загружается отдельным модулем. Качество и ограничитель кадров независимы: 20 / 30 / 60 FPS. Проверено 30 FPS в текущем встроенном браузере; производительность на конкретном слабом ноутбуке требует проверки на устройстве.
- Пока нет восстановления гостевой сессии после очистки cookie, управления ролями/исключения участников. Не использовать непредсказуемую ссылку комнаты как полноценную корпоративную модель доступа.
- Spreo использован как функциональный ориентир. По обновлённому запросу Jinaly развивается как самостоятельная игра и инструмент ретроспектив; точная копия интерфейса и полный паритет интеграций не являются целью. [Исходный аудит](docs/spreo-audit.md).

## Публикация

Проект зарегистрирован в Sites через `.openai/hosting.json`. Публикуйте собранный Worker вместе с миграциями из `drizzle`; не переносите локальную базу или сессионные cookie в исходный код. Сначала проверка и сборка, затем сохранение версии и публикация для выбранной аудитории.
