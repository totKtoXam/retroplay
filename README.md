# Jinaly · Retro 3D

Совместные ретроспективы в браузере: игровой мир от третьего лица и обычная доска работают с одним состоянием комнаты. React, TypeScript, Three.js, Vinext, Cloudflare D1.

## Запуск

Нужны Node.js 22.13+ и npm. В PowerShell используйте `npm.cmd`.

```sh
npm ci
npm run db:local
npm run dev -- --host 0.0.0.0
```

Откройте http://localhost:3000. Создайте комнату, введите имя и передайте ссылку участникам. Для подключения с другого компьютера нужен доступный ему адрес сервера: `localhost` обозначает компьютер самого участника. Веб-публикация Sites по умолчанию доступна только владельцу; для команды необходимо отдельно настроить аудиторию сайта.

Комнаты и карточки сохраняются в D1. Локальная база находится в `.wrangler` и не попадает в Git или веб-публикацию. Локальное и опубликованное приложения имеют разные базы. Не удаляйте `.wrangler`, если нужны локальные комнаты.

## Управление

| Действие | Ввод |
|---|---|
| Начать / продолжить игру | Клик по миру или «Играть» |
| Камера | Движение мыши без удержания кнопок |
| Курсор для меню | Esc |
| Движение | WASD |
| Прыжок | Пробел |
| Сесть / встать | C |
| Лечь | Двойное C |
| Бег / медленный шаг | Ctrl / Shift |
| Доска рядом | E |
| Вернуть камеру за персонажа | F |
| Приближение / отдаление | Alt + колесо, кнопки камеры |
| Инвентарь | 1–0, колесо |
| Круговое меню | Удерживать среднюю кнопку мыши |
| Краска / конфетти | 1 / 2, затем ЛКМ |
| Участники, задержка, FPS | Удерживать Tab или кнопка участников |

Первый клик активирует обзор и не стреляет. При разрешённом Pointer Lock курсор захватывается и камера вращается неограниченно. При запрете захвата во встроенном браузере обзор работает внутри окна; у его краёв продолжается горизонтальный поворот. Esc возвращает курсор. Панели приостанавливают игровой ввод.

Для Ctrl+W и других сочетаний, зарезервированных браузером, включите полный экран кнопкой в шапке. При поддержке браузером запрашивается Keyboard Lock. Встроенное окно может не поддерживать системный захват; разрешения браузера приложение не обходит.

Время суток и сезон меняет ведущий кнопкой над миром. Оформление, интерьер и качество доступны в настройках комнаты. Есть темы Наурыза, Дня единства, Дня Республики, Дня независимости, Нового года и горного лагеря. Краска постепенно исчезает; игровые эффекты не меняют карточки.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
# При работающем localhost:3000:
npm run test:integration
npm run build
```

`lint` проверяет код приложения, API и тесты. Неиспользуемые компоненты исходного shadcn-каталога `components/ui` не входят в этот lint scope; весь TypeScript входит в typecheck.

Модель проверяется на права ведущего, приватность, анонимность, голосование, архив и импорт. HTTP-проверка создаёт отдельные тестовые сессии и комнаты, проверяет конкурентные записи, лимит голосов, историю, отмену, изоляцию комнат и передачу краски; затем архивирует тестовые комнаты.

## Архитектура и ограничения

- Сервер выдаёт HttpOnly cookie; публичный ID участника — SHA-256 от сессионного секрета, а не сам секрет.
- Приватные карточки и чужие активные голоса исключаются из ответа сервера. Проверка прав выполняется в API.
- Изменения комнат проходят через контроль версии и атомарный пакет D1; история хранит последние 40 операций.
- Присутствие и игровые события синхронизируются периодическим HTTP-опросом примерно раз в секунду с интерполяцией аватаров. Это ещё не транспорт для динамичного соревновательного шутера.
- Геометрия объединяется по материалам, конфетти используют instancing, 3D загружается отдельным модулем. Экономичный режим ограничен 30 FPS, высокий — 60 FPS. Проверено 30 FPS в текущем встроенном браузере; производительность на конкретном слабом ноутбуке требует проверки на устройстве.
- Пока нет восстановления гостевой сессии после очистки cookie, управления ролями/исключения участников и серверного ограничения частоты стрельбы. Не использовать непредсказуемую ссылку комнаты как полноценную корпоративную модель доступа.
- [Аудит Spreo и точные границы совместимости](docs/spreo-audit.md). Полного функционального соответствия Spreo пока нет.

## Публикация

Проект зарегистрирован в Sites через `.openai/hosting.json`. Публикуйте собранный Worker вместе с миграциями из `drizzle`; не переносите локальную базу или сессионные cookie в исходный код. Сначала проверка и сборка, затем сохранение версии и публикация для выбранной аудитории.
