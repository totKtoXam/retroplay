## Реализация

RoomHub сохраняет версионированный JSON checkpoint в собственной существующей SQLite Durable Object storage. Счёт, раунд, фаза, абсолютные сроки, жизни, HP, журнал эффектов, боезапас, перезарядка и номера подтверждений восстанавливаются вместе. Сохранение боевых команд происходит перед HTTP/WS подтверждением. Обычная телеметрия движения сохраняется пакетно с прежним интервалом 2 секунды, поэтому авария может потерять последние позиции в этом окне.

D1 остаётся источником списка участников, профилей и настроек. Удалённые участники из checkpoint не воскрешаются. При смене карты старый checkpoint не применяется. Неизвестный формат явно отклоняется. Для старых комнат без checkpoint сохранено прежнее первичное создание матча; ретроспективно восстановить потерянное до этого релиза состояние невозможно.

Рестарт больше не создаёт новый матч и не вызывает дополнительное возрождение для восстановленной комнаты. Таймеры остаются привязаны к серверному времени: время остановки сервера не приостанавливает раунд или перезарядку. Изменений правил стрельбы, урона, движения и баланса нет.
