# Аудит исходной ретро-доски

Исходная доска: https://spreo.io/BOUYED1PZFZV. Изучена 6 сентября 2026 года через авторизованный интерфейс. Просмотрены инструменты, меню карточек, гаджеты и меню доски; исходные карточки и настройки не изменялись. Название шаблона — Good / Bad / Start / Stop.

Справочные источники: [инструменты Spreo](https://docs.spreo.io/boards/the-tools), [справка](https://spreo.io/help-and-guides), [возможности](https://spreo.io/about/facts). Праздничные темы сверены с [официальным календарём Казахстана](https://www.gov.kz/article/33969?lang=en) и [описанием культуры](https://www.gov.kz/article/64578?lang=en). Наурыз — 21–23 марта, День единства — 1 мая, День Республики — 25 октября, День независимости — 16 декабря, Новый год — 1–2 января. Приложение не вычисляет переносы выходных.

| Возможность исходной доски | В Jinaly |
|---|---|
| Стикеры, карточки, задачи, страницы | Создание, редактирование, цвета, теги, размер, поворот, владелец, срок, готовность |
| Приватное написание и раскрытие | Серверная фильтрация скрытых карточек, раскрытие собственных записей |
| Анонимность | Скрытие авторов чужих заметок и соответствующих записей истории |
| Группировка | Именованные группы и привязка карточек; свободное пространственное объединение в контейнер пока ограничено |
| Комментарии и реакции | Комментарии, emoji-реакции; внешних уведомлений об упоминаниях нет |
| Голосование | Раунды, бюджет, возврат голоса, скрытие чужих голосов до завершения |
| Маркер, текст, фигуры, соединители | Рисование, текстовые элементы, фигуры, связи двух карточек |
| Зоны и рамки | Четыре рабочие зоны и рамки; рабочее поле ограничено, не бесконечный холст |
| Таймер, спиннер, счётчик, звонок | Общий таймер, выбор участника/варианта, счётчик, привлечение внимания |
| Jukebox | Синтезированные мелодии с локальным выключателем звука; загрузки собственной музыки нет |

| Импорт / экспорт | JSON/CSV карточек; специализированного импорта формата Spreo и PNG-снимка всей доски нет |
| Шаблоны | Два исходных шаблона, несколько праздничных оформлений; публикации собственного шаблона в библиотеку нет |
| Изображения | HTTPS-ссылки с отображением поддерживаемых изображений; файлового хранилища загрузок нет |
| Управление доской | Название, архив, блокировка, ведущий, этапы встречи, приглашение ссылкой, фокус на зоне |
| Jira, библиотека иконок, сложные roadmap/calendar | Не реализованы: Jira-синхронизация, каталог 30 000 иконок, специализированные календарные/roadmap-виджеты |
| Командный доступ | Изолированные комнаты и гостевые сессии; корпоративных аккаунтов, SSO и полноценного редактора ACL нет |

3D и обычный режим используют одну модель и сервер. Положение, комментарии, группы, задачи и голоса не теряются при переключении. Дополнительно реализованы аватары от третьего лица, камера, движение, прыжок, позы, инструменты, монитор комнаты, интерьер/ландшафт, времена года и суток.

Этот документ фиксирует фактический охват, а не утверждает полное соответствие Spreo. Для полного паритета требуется отдельная реализация отсутствующих пунктов и расширенная совместная приёмка.
